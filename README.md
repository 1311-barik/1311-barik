## Избранные проекты

### Поймай AI

Мобильная квиз-игра «человек против ИИ»: игрок определяет, какой из двух материалов создан человеком, а какой — AI. В проекте есть мобильный клиент, API, админка, контентное ревью, аналитика и механика шеринга.

**Стек:** React Native, Expo, Next.js, TypeScript, PostgreSQL  
[Репозиторий](https://github.com/1311-barik/poymai-ai) · [Рабочая версия](https://poymai-135-181-197-13.nip.io)

### Тренажёр

Персональный PWA для силовых тренировок: готовые программы, подбор упражнений, карточки с техникой, таймер отдыха, история занятий и офлайн-режим. Контент синхронизируется из Google Sheets и Google Drive без участия разработчика.

**Стек:** React, TypeScript, Vite, Python, Google APIs, PWA  
[Репозиторий](https://github.com/1311-barik/trenazher) · [Рабочая версия](https://trenazher-135-181-197-13.nip.io)

### Недельный планировщик

Персональный PWA-планировщик с недельной сеткой, drag-and-drop, разбором задач из свободного текста, нормами нагрузки, режимом отъезда, отменой действий, статистикой и серверным хранением данных.

**Стек:** Next.js, TypeScript, Tailwind CSS, Prisma, SQLite, Playwright  
[Репозиторий](https://github.com/1311-barik/zhenya-weekly-planner) · [Рабочая версия](https://planner-135-181-197-13.nip.io)

## Проекты с закрытым исходным кодом

### Сайты и продукты Corp.Edu

Единая система образовательных и B2B-лендингов: публичный сайт курса, корпоративный лендинг, версия для рынка Казахстана и личный сайт AI-консультанта. Актуальная кодовая база собрана в приватном монорепозитории `education-websites`; прежние `corp-edu-landings`, `corp-edu-b2b` и `barskiy-site` сохранены как архив истории разработки.

[AI для своих задач](https://aiforpeople.online) · [Личный сайт](https://aiforteams.me)

### CRM-бот

Персональная CRM в Telegram: клиенты, сделки, история контактов, поиск, следующие шаги, ежедневные напоминания, еженедельные отчёты и резервное копирование. Данные хранятся в Airtable.

**Стек:** Python, Telegram Bot API, Airtable, APScheduler

### Семейный бот

Telegram-ассистент для учёта расходов, календаря и напоминаний. Понимает свободный текст, формирует отчёты и синхронизирует данные с Google Sheets и Google Calendar.

**Стек:** Python, Telegram Bot API, Google Sheets, Google Calendar, Claude API
